Xeno-Linux
GitHub Repository

Simplified Wine/Proton Environment

Automation script to manage and structure prefix isolation on Linux.

How to use See source code

Isolated Structure

Ensures that the local WINEPREFIX is set up without polluting your default user environment.

Quick Installation Guide

1. Clone the repository 
git clone https://github.com/deadgl/xeno-linux.git
cd xeno-linux
2. Get the Xeno executable

Download the installer manually from Xeno and move it to the destination directory indicated in the documentation: 

~/.wine_roblox_xeno/drive_c/Xeno/
3. Make the script executable and run it 
chmod +x launch.sh
./launch.sh
