Isolated Structure

Quick Installation Guide

1. Clone the repository 
git clone https://github.com/deadgl/xeno-linux.git
cd xeno-linux
2. Get the Xeno executable.

Download the installer manually from Xeno and move the executable (e.g.: Xeno-v1.3.55.exe) to the destination directory: 

~/.wine_roblox_xeno/drive_c/Xeno/
3. Make the script executable and run it. 
chmod +x launch.sh
./launch.sh
