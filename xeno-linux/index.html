Simplified Wine/Proton Environment

An automation script to structure and manage isolated Wine prefix directories on Linux[cite: 2, 27].

How to Use View Source Code

Isolated Structure

Ensures your local WINEPREFIX is safely configured without cluttering your main user directory[cite: 27].

Quick Setup Guide

1. Clone the repository 
git clone https://github.com/deadgl/XENO-LINUX.git
cd XENO-LINUX
2. Obtain the Xeno executable

Download the latest installer manually from xeno.now/method and move the downloaded executable (e.g., Xeno-v1.3.55.exe) to the target directory[cite: 111, 112]: 

~/.wine_roblox_xeno/drive_c/Xeno/
3. Make the script executable and run 
chmod +x launch.sh
./launch.sh
